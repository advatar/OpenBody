# SPARC autonomic release watch

Research-only metadata for OpenBody issue #58 / epic #57.

This directory records **release and qualification state**, not therapy guidance.
It is intentionally compact so Vagus Therapy can eventually consume a qualified
read-only receipt without downloading SPARC artifacts or reproducing models.

Evidence classes are non-promoting:

```
anatomical variability/connectivity
!= simulated recruitment
!= measured target engagement/physiological response
!= clinical benefit
```

A resource with `material_update: false` means the research watch found no
consequential release since the stated checkpoint. It is not a new release.

The initial manifest freezes the state established by the 25 September and
2 October 2026 Vagus Therapy briefs. Upstream authentication/digests and
reproduction receipts remain owned by the dedicated qualification work (#22,
#25, #57 children); this file must not manufacture stronger qualification.
